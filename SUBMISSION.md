### Project description *
*Briefly explain your project’s concept and what artifacts it produced. What’s the motivation behind your project? 100–200 words.*

ExplainQuantumComputing is an interactive, paper-themed visual explainer created to bridge the wide gap between pop-science quantum misconceptions and authentic quantum complexity theory. Popular media frequently claims quantum computers are fast because qubits "try all possible paths simultaneously in parallel worlds." In reality, this model is false—unfiltered quantum measurement yields a random guess.

The artifact produced is a comprehensive 19-slide interactive digital publication featuring an interactive continuous-rotation angle wheel, a step-by-step classical Turing tape, a 3-SAT Boolean logic circuit schematic with live interactive gates, an exponential truth table inspector, a geometric Grover amplitude amplification sandbox, and live quantum state measurement collapses.

Our motivation is to give curious developers, students, and enthusiasts an honest, intuitive, and empowering mental model of quantum computation. Instead of hand-waving mysticism, we demonstrate how quantum computers physically evolve a real $2^n$-dimensional complex amplitude state vector, employing constructive and destructive interference like an Archimedean lever to cancel incorrect computational branches and amplify correct solutions before measurement. By integrating real Moth Atlas quantum executions into the slides, readers directly observe quantum mechanics in action.

### Technical description *
*Briefly describe the tools and techniques used to create the work—including which Moth Atlas engines were used. 50–100 words.*

Engineered as a responsive, dependency-light web application utilizing HTML5, modern CSS themes, ES6 JavaScript, and KaTeX for LaTeX mathematical typesetting. It connects directly to Moth Quantum's Atlas `graph-v1` engine to execute live 1,024-shot jobs verifying two core quantum principles: 2-qubit separable vs entangled Bell-state correlation and 3-qubit superposition collapse across complex amplitudes ($1/4 + i/4$). It features seamless execution across real IBM QPUs, Moth Cloud Emulators, and a zero-dependency Mulberry32 PRNG simulator. A Vercel Edge Proxy (`api/[...path].js`) handles CORS routing with zero authentication latency.

### QPU or emulation? *
*Does your project use emulation, or actual quantum hardware (QPUs)?*

Both QPU and emulation.

Readers can dynamically choose their target via the 🦋 **Moth Settings** header pill:
1. **Real Quantum Hardware (`qpu`)**: Dispatches the 2-qubit Bell state or 3-qubit state vector to physical IBM quantum processors through the Moth Atlas API, retrieving authentic quantum measurement distributions.
2. **Cloud Emulator (`emu`)**: Executes quantum state preparations on Moth Atlas cloud infrastructure for immediate verification.
3. **Local Quantum Simulator (`local`)**: Deterministic client-side Mulberry32 PRNG fallback that generates exact theoretical and noisy quantum probability distributions with zero setup or API costs.
